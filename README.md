# LoRaWAN Hardening Lab

Interactive simulator for OWASP ISVS 4.6.2 (hardening of the network, join and application servers of a ChirpStack LoRaWAN back-end).
Switch controls on and off, run 12 attacks, and watch the score and the generated configuration change.

Run locally: `python3 -m http.server 8080` then open http://localhost:8080
Test: `npm install && npm test`
